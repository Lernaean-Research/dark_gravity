# AI Reproduction Package: Kitcey (2026)

## 1. Purpose

This package contains all necessary source files, data, and instructions for an AI assistant to faithfully reproduce the paper "Intrinsic Response Sector as Dark Gravity: A GR-Compatible Candidate Identity for the Cold Dark Matter Role (SPARC-175)" by Robert D. Kitcey, version 5.1.0.

The goal is 100% faithful, pixel-perfect reproduction from the contents of this package alone.

## 2. File Manifest

-   `main.tex`: The master LaTeX source file for the paper.
-   `references.bib`: The BibTeX bibliography file containing all citations.
-   `aastex631.cls`: The required LaTeX class file for AAS (American Astronomical Society) journals.
-   `bic_comparison_figure.png`: Figure 1 in the paper. This is a pre-generated asset.
-   `bic_scatter_figure.png`: An auxiliary figure, not included in the final paper but part of the analysis.
-   `sparc_analysis.py`: The Python script used to perform all data analysis and generate the figures and summary data.
-   `sparc_summary.json`: The summary data generated by `sparc_analysis.py`, containing the key numerical results reported in the paper.
-   `README.md`: This instruction file.

## 3. Reproduction Instructions

### 3.1. Environment Prerequisites

The target environment is a standard Linux system (e.g., Ubuntu 22.04) with the following installed:

1.  **A full TeX distribution:** `texlive-full` is recommended.
    ```bash
    sudo apt-get update && sudo apt-get install -y texlive-full
    ```
2.  **Python 3.11+** with the following packages:
    -   `numpy`
    -   `pandas`
    -   `scipy`
    -   `matplotlib`
    ```bash
    pip3 install numpy pandas scipy matplotlib
    ```

### 3.2. Compilation from Pre-Generated Assets

This is the primary, direct reproduction path.

1.  **Navigate** to the root of this package directory.
2.  **Compile the LaTeX document** using the following standard sequence:

    ```bash
    pdflatex main.tex
    bibtex main
    pdflatex main.tex
    pdflatex main.tex
    ```
3.  **Verify the output:** A file named `main.pdf` should be generated. This is the final, reproduced paper.

### 3.3. (Optional) Full Regeneration of Figures and Data

This step regenerates all analytical results from the source script.

1.  **Ensure prerequisites** from 3.1 are met.
2.  **Navigate** to the root of this package directory.
3.  **Run the analysis script:**

    ```bash
    python3.11 sparc_analysis.py
    ```
4.  **Verify outputs:** This will overwrite the following files with regenerated versions:
    - `bic_comparison_figure.png`
    - `bic_scatter_figure.png`
    - `sparc_summary.json`
    - `sparc_bic_results.csv` (a detailed data table)

5.  **Re-compile the paper** using the steps in 3.2 to produce the final PDF with the newly generated assets.
