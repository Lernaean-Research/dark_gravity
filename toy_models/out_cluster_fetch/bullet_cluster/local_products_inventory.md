## What these products give you

To run `cluster_profile_q_est.py` apples-to-apples with SPARC, you need a 1D profile of either `(v_tot_kms, v_bar_kms)` or `(M_tot_Msun, M_bar_Msun)` vs radius.

- **Baryons (M_bar)**: can be derived from X-ray surface brightness + spectral temperature/metallicity (gas density profile + gas mass). That uses event lists + exposure maps + responses/spectra products.
- **Total (M_tot)**: can be obtained either from (a) lensing mass models (usually from optical/IR data, not included here) or (b) hydrostatic equilibrium using X-ray density+temperature gradients (uses these X-ray products).

**Important limitation**: A Bullet-Cluster *lensing* test (2D mass centroid offsets) requires lensing mass maps/shear catalogs from optical/IR imaging. The HEASARC X-ray downloads do not contain those; they support the gas (baryon) side strongly.
