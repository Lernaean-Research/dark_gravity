Strong lensing model version 1.0 (July 2016) for the galaxy cluster MACS J0416.1-2403 presented in Caminha et al. 2016 (arXiv:1607.0346).

For more details please see the paper Caminha et al. 2016 (arXiv:1607.0346).
The full CLASH-VLT spectroscopic catalogue, combining VIMOS and MUSE, can be found in https://sites.google.com/site/vltclashpublic/ .

The modelling is performed with the software lenstool (Kneib et al 1996, Jullo et al 2007, Jullo & Kneib 2009) and using the position of multiple images as constraints.
The mass model is constituted by a combination of PIEMD halos.
We use a total of 102 multiple images belonging to 37 families (all with spectroscopic confirmation) in a range of z=0.940 to z=6.145.
Families with unknown spectroscopic redshifts are not considered in this model, significantly reducing systematic effects in the modelling.

In addition to the lensing maps, we also release the lenstool configuration files, the best fitting model and the full MCMC chain.

The cosmological parameters used in the calculations are:
Omega_m = 0.3; Omega_l = 0.7; h_0 = 0.7; w_eos = -1

The folder lenstool_files contains the configuration files used in our SL model and some outputs.
The file Caminha2016_lenstool_README.txt contains a short description of these files.
