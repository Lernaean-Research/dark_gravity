## Delivered files:

# i) Best-fit models of potential (psi), deflection (alpha1,2), convergence (kappa), shear (gamma1,2) scaled such that DLS / DS = 1, and magnification (magnif) at z=1,2,4,9

# ii) 100 additional reconstructions for each best-fit model lensing quantity with the same redshift scaling.
# created by bootstrap-resampling strong lensing catalogs. In v1, reconstructions were created by bootstrap-resampling weak lensing catalogs.
# The increased number of strong lensing systems used in v2 merited this change.  

## Description of lensing reconstruction technique: 

# Strong and Weak Lensing United developed by M. Bradac
# http://adsabs.harvard.edu/abs/2005A%26A...437...39B
# http://adsabs.harvard.edu/abs/2009ApJ...706.1201B

# Model inputs: strong lensing multiple image catalog, weak lensing galaxy catalog, lens model (no light traces mass assumption)
# The v2 model is described in detail in Wang et al. 2015 (arXiv:1504.02405)
# References for model inputs are also found in Wang et al. 2015.
